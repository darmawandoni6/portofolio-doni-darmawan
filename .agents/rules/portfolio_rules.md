# Portfolio Maintenance Rules

- **Centralized Data**: All personal information, resume experience, skills, and NPM package details MUST be stored and updated in `src/data/cvData.ts`.
- **Styling Standards**: Maintain dark modern aesthetic (`bg-slate-950`), glassmorphism cards, and responsive layouts.
- **Verification Requirement**: ALWAYS run `npm run build` after making edits to ensure TypeScript compilation passes.
- **Asset Integrity**: Keep `public/assets/CV_Doni_Darmawan.pdf`, `public/assets/me.png`, `public/assets/banner.png`, and `public/assets/banner.svg` accessible.
